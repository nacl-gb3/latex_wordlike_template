# LaTeX Word-like Template

With this configuration, you can start moving away from using word processors
like Microsoft Word, Google Docs, and even LibreOffice Docs.

You are now free to write your school essays in any text editor that you want.
You can write your essays in Vim. You can write your essays in Emacs. You can
write your essays in VS Code.

The choice is yours. You are now free. 🔥 

Here are some helpful resources to get started:
* [Guide on how to install LaTeX locally on Windows](https://gist.github.com/Foadsf/768e6f023c45e3d078be7793cdb9e102)
* To install LaTeX (and desired libraries) on Linux, check your distro's documentation or guides online
  * [Good starting point](https://linuxconfig.org/introduction-to-latex-on-linux)
* [texlab](https://github.com/latex-lsp/texlab)
* [latexindent](https://latexindentpl.readthedocs.io/en/latest/sec-appendices.html#linux)
* [harper-ls](https://writewithharper.com/docs/integrations/language-server)
* [Learn LaTeX in 30 Minutes](https://www.overleaf.com/learn/latex/Learn_LaTeX_in_30_minutes)
* [Paragraphs in Overleaf](https://www.overleaf.com/learn/latex/Paragraphs_and_new_lines)

If you have any questions, please make an issue and I shall do my best to help or at
least point you in the right direction
